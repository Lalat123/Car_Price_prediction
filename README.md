🚗 Car Price Predictor
      This project uses Machine Learning to predict the resale value of cars based on various features such as mileage, brand, fuel type,          and year of manufacture.

📌 Project Overview
      The goal of this project is to provide accurate price estimations for used cars. This can help both buyers and sellers determine a 
      fair market price using historical data.

📊 Dataset
      The dataset used for this project was sourced from Kaggle. It includes features such as:
      * Model of The car
      * Year , transmission 
      * Milege , fueltype , engineSize
      * Tax, mpg
      * Price of the Car
🛠️ Tech Stack
      * Python
      * pandas
      * numpy (Data Preprocessing)
      * matplotlib & seaborn (Exploratory Data Analysis)
      * scikit-learn (Model Building & Evaluation)
